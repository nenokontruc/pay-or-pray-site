# Legacy site (reference only)

`index.html` and `i18n.js` are the original single-file website, unchanged
(identical to git tag `html-baseline`, commit `ea3a782`).

They are kept here as the reference implementation during the React migration:

- the Simulation's business logic is copied from here for the golden-master tests;
- every sentence, figure and citation on the React pages is checked against it.

Do not edit these files. To view the original site locally while the dev server
is running, open `/legacy/index.html`.
